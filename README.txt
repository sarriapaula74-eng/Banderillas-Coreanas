# Corn Dog — página web

Página web hecha únicamente con HTML5, CSS3 y JavaScript, siguiendo el documento proporcionado.

## Archivos
- index.html — estructura y contenido
- styles.css — diseño responsive, colores y animaciones
- script.js — menú móvil, desplazamiento suave y animaciones de entrada

## Antes de publicar
1. Sustituye el enlace de WhatsApp de `index.html` por el número real.
2. Sustituye el enlace de Instagram por el perfil real.
3. Si tienes el archivo `Logo Corn Dog - copia.jpeg`, puedes incorporarlo como logo real en el encabezado.
4. Las ilustraciones actuales son CSS para que el proyecto funcione sin dependencias de frameworks.

La identidad sigue lo indicado: blanco, naranjas y vino tinto; estilo moderno/juvenil; títulos serif de alto contraste y texto limpio.
